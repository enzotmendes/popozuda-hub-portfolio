# Popozuda Hub


**Análise de e-commerce com vendas, custos, margens e desempenho por canal.**


## Minha participação


Desenvolvi o projeto do zero. A apresentação descreve o sistema e suas integrações sem publicar código-fonte privado, dados de clientes ou valores da operação.


## Problema abordado


Comparar a operação de vários canais exige reunir vendas, taxas, reembolsos, custos e informações de produtos. O sistema oferece uma visão consolidada e recortes por canal, produto e período.


## Entregas funcionais


- Painel consolidado de faturamento, resultado operacional, margens e pedidos.
- Participação por canal e análise de desempenho por produto.
- Acompanhamento de cancelamentos, custos e dados financeiros.
- Módulos de afiliados, lives e anúncios no escopo da plataforma.
- Filtros por período para consultar os indicadores.


## Integrações e tecnologias


| Camada | Tecnologias e serviços |
| --- | --- |
| Marketplaces e lojas | TikTok Shop, Mercado Livre, Shopee e Shopify |
| ERP | Bling |
| Pagamentos | Appmax |
| Dados | PostgreSQL e Supabase |
| Aplicação | TypeScript, Vite, Node.js e Hono |


O foco do projeto é análise e integração de dados de comércio. Não é atribuída uma funcionalidade de IA ao sistema sem evidência específica.


## Resultado apresentado


Visão consolidada de indicadores de diferentes canais, com análise por período e produto. O painel e o filtro foram utilizados para produzir a captura sem exportar dados ou alterar registros.


Faturamento e variações de vendas não são apresentados como resultados pessoais de desenvolvimento, e não foram inventadas estimativas de tempo economizado.
