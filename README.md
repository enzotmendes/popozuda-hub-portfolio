# Popozuda Hub

Criei o Popozuda Hub do zero para analisar vendas de diferentes canais em um só lugar.

O painel reúne pedidos, taxas, reembolsos, custos e margens. É possível olhar os números por período, canal e produto. A plataforma também contempla afiliados, lives e anúncios.

**Integrações:** TikTok Shop, Mercado Livre, Shopee, Shopify, Bling e Appmax.

**Tecnologias:** TypeScript, Vite, Node.js, Hono, PostgreSQL e Supabase.

Este repositório descreve o produto sem publicar código privado nem dados da operação.
